# Посмотри в окно

Учебный проект Яндекс Практикума. Приложение показывает видеозарисовки из разных городов. Видео можно искать по городу и времени суток и выбирать из списка карточек.

## Локальный запуск

В корне проекта запустите HTTP-сервер с помощью Python 3:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Для загрузки карточек и видео нужен доступ к каталогу Практикума.

[Репозиторий проекта на GitHub](https://github.com/AKArtes/posmotri-v-okno-ad)
